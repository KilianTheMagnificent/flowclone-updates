# FlowClone — Release Builds & Update Notes

Release builds and update notes for **FlowClone**, a personal macOS voice dictation app maintained by [Andre Romero-Carey](https://github.com/KilianTheMagnificent).

- **Purpose of this repository:** Hosts macOS installer builds and changelogs used by the app's built-in updater via [GitHub Releases](https://github.com/KilianTheMagnificent/flowclone-updates/releases).
- **Source code:** Maintained in a separate private repository.
