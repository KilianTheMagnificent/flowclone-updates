# FlowClone — macOS Release Channel

Official public release and auto-update channel for **FlowClone**, a native local-first macOS voice-to-text dictation utility maintained by [Andre Romero-Carey](https://github.com/KilianTheMagnificent).

- **Purpose of this repository:** Hosts code-signed macOS installer builds and release notes consumed by the app's built-in updater via [GitHub Releases](https://github.com/KilianTheMagnificent/flowclone-updates/releases).
- **Source repository:** Maintained privately; only signed release artifacts and changelogs are published here.
