# Security Policy

## Scope

This repository hosts macOS release artifacts, checksums, and release notes for **FlowClone**. Application source code is maintained privately.

## Reporting a Vulnerability

If you discover a security issue with a published release artifact, signature, checksum, or updater feed in this repository, please **do not** open a public issue.

Instead, report it privately via [GitHub Security Advisories](https://github.com/KilianTheMagnificent/flowclone-updates/security/advisories/new) with:

- The affected release tag or asset filename.
- Steps to reproduce or verify the issue.
- Any relevant hashes, logs, or impact details.

Reports are reviewed by the maintainer as promptly as possible, and confirmed issues will be addressed with an updated release and advisory where appropriate.
